A system is not a list of assets. It is a set of paths — the routes by which
something moves from an ingress point to something it can touch. Most security
work is spent reconstructing those paths after the fact, in a spreadsheet or a
ticket, and then watching the reconstruction go stale.

**Atlas** keeps the map current. It ingests state from cloud, on-prem, and edge
sources, normalizes it into one graph model, and holds the relationships that
matter: which identity can reach which service, which service can read which
data, which asset sits at the end of which chain.

The point is not the map itself. The point is that when you ask *“what can reach
this asset?”* the answer comes back from the live graph, not from last quarter's
audit. The path an attacker would take is the path the map already knows about.

That is the premise the rest of the suite reads from. Query it, traverse it, put
an interface in front of it, prove what was decided against it — all of it starts
with the map.
